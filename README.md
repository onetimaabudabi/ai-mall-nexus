# AI Mall Connect

Создай дизайн-систему и прототип маркетплейса "AI-Mall" — B2B-платформы с ИИ-агентами для продавцов и покупателей. Проект разрабатывается для хакатона Росэлторг, поэтому дизайн должен сочетать инновационный AI-дух с корпоративной премиальностью.

Главная задача — объединить в дизайне лучшие практики Apple (минимализм и ясность), Wildberries (строгая монохромная эстетика раздела "Бренды") и Ozon (продуманный UX и навигация). Интерфейс должен выглядеть дорого, чисто и высокотехнологично.

## 🎨 Дизайн-философия

1. **От Apple:** Ясность (Clarity), сдержанность (Deference) и глубина (Depth). Минимум декора, максимум контента. Полупрозрачные стеклянные фоны (glassmorphism) для модальных окон и навигации. Используй только необходимые элементы, каждый должен быть оправдан.

2. **От Wildberries:** Монохромная база (белый, серый, черный) как основа для ощущения порядка и премиальности. Акцентный цвет — дозированно, только для ключевых CTA и активных состояний.

3. **От Ozon:** Продуманная механика поиска, фильтрации и умных подсказок. Интерфейс должен предвосхищать действия пользователя.

## 🖌️ Конкретные дизайн-требования

**Цветовая палитра:**

- Основной фон: #FFFFFF (белый) и #F5F5F7 (светло-серый для секций).

- Текст: #1D1D1F (заголовки), #6E6E73 (второстепенный).

- Акцент (Brand): #1a2744 (глубокий синий) для CTA-кнопок и активных элементов. Дополнительный акцент — сдержанный золотой #C9A84C для премиум-статусов.

- Чёрный (#000000) для эксклюзивных меток ("Премиум", "Оригинал").

**Типографика:** Шрифт Inter или SF Pro. Четкая иерархия: крупные жирные заголовки, лёгкий текст для описаний.

**Компоненты:** Карточки товаров — "воздушные", с минималистичной информацией (изображение, название, цена, кнопка). Навигация — иконки в монохроме, интуитивная. Баланс отступов и "воздуха", чтобы интерфейс дышал.

## 📱 Страницы и функциональность

### 1. Главная (Landing Page)

- Герой-секция на всю ширину с анимированным заголовком "AI-Mall — Умный B2B маркетплейс".

- Подзаголовок: "ИИ-агенты помогают продавцам и покупателям находить друг друга, вести переговоры и автоматизировать документы".

- Две крупные кнопки CTA: "Стать продавцом" и "Найти товары" — в акцентном синем цвете с градиентным свечением при наведении.

- Секция с тремя карточками преимуществ: "ИИ-поиск", "Умные переговоры", "Автоматические документы" — с простыми иконками.

- Временная линия "Как это работает" (4 шага) в минималистичном стиле.

- Футер с логотипом AI-Mall и контактами.

### 2. Дашборд (личный кабинет)

- Боковая навигация (слева) с иконками: Главная, Мои товары, Заявки, Чат-переговоры, Документы, Настройки.

- Верхняя панель: логотип AI-Mall, строка поиска, аватар пользователя с выпадающим меню.

- Главный экран дашборда: карточки статистики (активные заявки, новые сообщения, ожидающие документы).

- Лента последних активностей в виде хронологического списка.

### 3. Каталог товаров (для покупателя)

- Сетка карточек (3 колонки) с фото, названием, ценой, рейтингом.

- Умные фильтры (категория, цена, рейтинг) и поиск с автодополнением (как у Ozon).

- На каждой карточке — кнопка "Запросить предложение", которая открывает чат с ИИ-агентом продавца.

### 4. Личный кабинет продавца

- Форма добавления товара: название, описание, цена, категория, загрузка фото.

- Список моих товаров с возможностью редактировать, архивировать и видеть статус (Активен, На модерации, Завершён).

### 5. Чат-переговоры с ИИ (Главная фича)

- Интерфейс мессенджера: список диалогов слева, окно чата справа.

- Сообщения от пользователя и ИИ-агента визуально разделены (как в iMessage).

- Визуализация статуса переговоров в виде индикатора: "Торг идёт" → "Согласовано" → "Документы готовы".

- Кнопка "Сформировать договор" появляется автоматически, когда статус "Согласовано".

- В чате отображаются карточки предложений с ценой, сроками и условиями.

### 6. Документы

- Список всех сгенерированных документов с датами и статусами.

- Кнопка "Скачать PDF" для каждого документа.

### 7. Профиль и настройки

- Форма редактирования профиля (имя, компания, контакты).

- Переключатель тёмной темы (опционально).

## ⚙️ Технические требования

- Стек: React + TypeScript + Tailwind CSS.

- Компоненты: shadcn/ui.

- Анимации: Framer Motion для плавных переходов.

- Полная адаптивность (мобильные, планшеты, десктоп).

- Все кнопки и элементы должны быть интерактивными, использовать моковые данные (товары, пользователи, сообщения).
